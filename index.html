WMS Operations

SYNTHETIC operations model — a transparent teaching heuristic, NOT a certification and NOT measured from a real site. Per-stage throughputs are documented order-of-magnitude assumptions (see wms.js). The KPIs mirror the ISO 22400 discipline (formula · elements · unit · time behaviour), grounded in standard warehouse practice.

Simulates the standard warehouse workflow — receiving → put-away → storage → replenishment → order-picking → packing → shipping — as a deterministic, seeded discrete flow of a synthetic order stream over the current layout (whatever is loaded: an example, a generated plant or a hand-built floor). The order-picking stage reuses the pick-travel simulation; each stage's throughput is derived from the layout (dock count, staging buffer, pick faces, pick-path length, automation lanes). Same layout + seed + orders → identical result.

Seed comes from the Simulation panel above, so the picking stage matches your sim run.

Run to see the 7-stage flow (per-stage throughput, load and backlog), the warehouse KPI summary and the bottleneck stage in plain language.

Live material flow

SYNTHETIC animation — a transparent teaching model, NOT a real discrete-event-simulation engine, NOT a measurement and NOT a certification. Boxes follow straight-segment waypoint routing between zone centroids (there is no queueing, congestion or pathfinding). Spawn/completion rate and travel speed follow the documented wms.js throughput heuristic.

Watch handling units (MUs) flow through the current layout along the spine receiving → storage → picking → packing → shipping, using dock, storage, pick-face and pack centroids (and a conveyor/RGV/AGV spine where present) as waypoints. More docks/automation → the bottleneck stage (via WMS) lifts, so units spawn faster and move quicker. Seed comes from the Simulation panel — same layout + seed → identical animation.

Press Play (or Step) to animate boxes moving through the warehouse. Pause returns to the normal edit view.

Compliance Check

Design aid, NOT a certification, legal-compliance guarantee, or Gefährdungsbeurteilung. Informed by German workplace guidelines (ASR A1.8, ASR A2.3, DIN 15185). Verify any real design with the official texts and a qualified professional.

Reviews the current layout against published German workplace-guideline values — working aisles (informed by DIN 15185), main traffic routes (ASR A1.8) and escape-route reachability/width (ASR A2.3). Each finding shows the measured value, the informed-by guidance value and the offending element. Deterministic, fully offline. The figures are guidance, not legally binding limits.

Run the check to see pass / warn / fail findings. Click a finding to highlight the element(s) on the floor.

Welcome to WarehouseTwin

A tiny, honest warehouse digital twin. Three steps and you are running.

  1. 1 · Place racks & docks. Click a palette item, then click the floor. Drag to move, keep a valid aisle between rack rows. Chain conveyors from storage to a pack station and the outbound dock — flow arrows show what is connected. The starter layout begins with its conveyor and stations disconnected on purpose: fixing its five flow warnings is your first exercise.
  2. 2 · Pick strategies. Choose slotting/picking (Random, ABC, Zone, Batch, Wave) and push vs pull replenishment on the right — or load the MRO preset for a full layout.
  3. 3 · Run the sim. Hit Run to see throughput, pick travel, storage fill, stockouts and overstock. Same seed → same result. Toggle Heatmap above the floor to see where the pickers walk, and compare experiments in Run history.

All data starts synthetic and seeded — and in the full version you can make it yours: Import your data (left panel) runs the sim on your own article/order CSVs, and Floor plan underlay lets you trace racks over a photo of your real hall. Icons and code are original/open. Nothing is sent anywhere — it runs fully offline.
